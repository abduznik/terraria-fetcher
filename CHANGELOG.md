# Changelog

All notable changes to this project are documented here. Dates are UTC.

## [Unreleased]

- **v2.0 "Beat the Wiki"**: six features scouted from recurring community complaints about the official/Fandom Terraria wikis, then shipped incrementally
  - Game version + data freshness badge on every page, with a "may be outdated" warning past 6 months old (#9)
  - Site-wide search across items, build guides, and the progression checklist, not just the item fetcher (#11)
  - "What's my next upgrade?" recommender on the builds page: pick class/stage, tick off owned gear, get a ranked shortlist instead of a full stage list (#10)
  - Per-build-guide "Verified for &lt;version&gt;" tag plus a pre-filled "Report this build as outdated" link (#12)
  - Mobile touch-target audit and fixes: larger checklist checkboxes, full-width controls on narrow viewports (#13)
  - Weapon DPS calculator on the Compare page: real per-class modifier tables (Legendary/Godly/etc.) and common buff toggles, backed by newly-fetched `useTime`/`critChance`/`knockback` data (#14)
- SEO pass: unique meta descriptions, Open Graph and Twitter Card tags, canonical URLs, JSON-LD structured data, `sitemap.xml`, `robots.txt`, and repo topics/description
- Replaced every decorative emoji with real Terraria item/NPC icons pulled from the wiki
- Fixed oversized item sprites (e.g. Zenith) overflowing their icon slots in search-suggestion dropdowns
- Added Back/Forward navigation history to the interactive crafting tree's re-root feature
- Repo scaffolding: issues, milestones, this changelog, and `ROADMAP.md`

## [1.3.0] - 2026-09-06

- Added a custom site favicon and icon set (Feral Claws holding a Suspicious Looking Eye), generated by compositing real wiki sprites
- Replaced all emoji glyphs across navigation, headings, and buttons with real Terraria item/NPC icons

## [1.2.0] - 2026-09-05

- Added the interactive crafting tree (`tree.html`): a visual node/branch diagram with SVG connectors, click-to-expand ingredients, and click-to-re-root navigation
- Added the Boss & Enemy Drops page (`bosses.html`): reverse lookup of every item a boss or enemy drops
- Added the Item Comparison tool (`compare.html`): side-by-side stats for up to four items
- Added a recursive crafting-chain view (later superseded by the interactive tree) to the item fetcher

## [1.1.0] - 2026-09-05

- Corrected several build guide errors: fixed "Cobalt Greaves" (should be "Leggings"), upgraded Early Hardmode gear recommendations to Adamantite/Titanium, and filled in missing Ranged/Mage/Summoner builds for the Post-Mech to Plantera stage
- Rewrote all class builds as complete, concrete loadouts instead of vague either/or option lists

## [1.0.0] - 2026-09-04

- Initial release: offline item and recipe fetcher, class build guides for every progression stage, progression checklist with localStorage persistence
- Terraria-themed UI (wood panels, dirt/sky background, item-slot styling)
- CI-driven data pipeline: `scripts/fetch_data.py` pulls items, recipes, NPCs, drop sources, and shop listings from the Official Terraria Wiki's Cargo API and commits them as static JSON
- Automatic GitHub Pages deployment on every data refresh or content push
